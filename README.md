An offline-first Electronic Medical Record (EMR) system specifically designed for ophthalmology clinics. 
This application ensures reliable patient data management, appointment scheduling, and clinical documentation 
even in environments with unstable or no internet connectivity.

## Key Features
* Offline-first data synchronization and local storage.
* Comprehensive patient registration and medical history tracking.
* Specialized ophthalmology exam workflows and diagnostic logging.
* Secure role-based access control for clinic staff.
* Fast, lightweight interface optimized for daily clinical operations.
